# Versioning

## Current baseline
- Current development version: 0.5.1
- Rationale: User-testing polish and bug-fix updates landed across board UX, sync behavior, and leaderboard scoring/ranking.

## Rules until first release
- Stay on major version 0 until first release.
- Epic completion bumps minor version.
- Story completion and bug fixes bump patch version.

Examples:
- 0.3.2 -> 0.3.3 for E3-S3 story completion.
- 0.3.3 -> 0.4.0 when Epic 4 begins as the next active epic line.

## First release
- First official release will bump to 1.0.0.

## Changelog format
- Keep one active top section for the current in-progress version.
- Keep prior versions as concise historical snapshots.
- Keep entries short and action-focused.
